    Duplicate · carry over values

    PRD 08 Status: Shipped Surfaces: Desktop form builder · Desktop journal · Mobile inspection All docs

    Authors mark fields with Option to duplicate value. On duplicate, inspectors can keep those answers — notes never copy. Mobile allows per-field uncheck; desktop keeps all keepable answers.

    1

    Design intent

    • Repeat without retyping stable answers (zone, asset).
    • Author-controlled risk — only opted-in fields are eligible.
    • Notes stay fresh — findings thread never clones.
    • Honest empty state — no dialog if nothing keepable.
    2

    3

    Feature logic

    • Flag optionToDuplicateValue (default off).
    • Keepable = flag + non-empty + uploaded https media.
    • Structure always copies; notes never copy.
    4

    User journey

    1. Author enables Option to duplicate value → sky Duplicate value chip.
    2. Inspector fills fields, taps Duplicate item / “+”.
    3. Chooses Keep vs Empty; mobile may uncheck fields.
    4. New item appears with kept answers; notes blank.

    Test cases

    IDStepsExpected results
    TC-DUP-001

    Duplicate with no keepable answers skips choice UI

    Pre: Requirement form has no fields with Option to duplicate value, or those fields are blank.

    1. On desktop: click Duplicate item.
    2. On mobile: tap “+” on the focused item.
    • No Keep/Empty dialog or sheet appears.
    • New item is created immediately with empty form answers.
    • Notes are not copied.
    • New item shares the same requirement id(s) for looping.
    TC-DUP-002

    Desktop Keep selected values copies all keepable answers

    Pre: Fields Zone + Asset ID have Option to duplicate value ON and are answered; item has notes.

    1. Click Duplicate item.
    2. Read dialog: “Keep these answers in the new item: Zone, Asset ID…”.
    3. Click Keep selected values.
    4. Open the new item below.
    • Dialog title is “Duplicate item”; actions Empty form / Keep selected values.
    • New item has Zone and Asset ID values copied.
    • Unflagged fields are blank even if answered on source.
    • Notes / message thread on the new item are empty.
    TC-DUP-003

    Desktop Empty form resets keepable answers

    Pre: Same source item as TC-DUP-002.

    1. Duplicate item → click Empty form.
    2. Inspect the new item.
    • All form fields on the new item are empty.
    • Structure/requirement ids still match source.
    • Notes empty.
    TC-DUP-004

    Mobile per-field uncheck before Next

    Pre: Mobile; source has ≥2 keepable answered fields.

    1. Tap “+”; sheet “Duplicate item” opens with Keep selected values defaulted.
    2. Under Values to keep, uncheck Asset ID; leave Zone checked.
    3. Tap Next.
    • New item has Zone copied; Asset ID blank.
    • Notes empty.
    • Selecting Empty form instead starts a fully empty form.
    TC-DUP-005

    Local-only media is not keepable

    Pre: Flagged image/file field answered with a local file:// or blob: URI (not yet uploaded).

    1. Trigger duplicate while that media is still local-only.
    2. Observe whether the field appears in keepable list / is copied on Keep.
    • Local-only media is excluded from keepable answers.
    • After upload to https://…, a later duplicate can offer that field as keepable.
    TC-DUP-006

    Authoring toggle + badge

    Pre: Web form builder open on a standard field (not special).

    1. Enable Option to duplicate value Switch in Field settings.
    2. Observe field card chips; Save; reload builder.
    • Sky callout copy matches: “When duplicating an item, inspectors can choose to keep this field’s answer.”
    • Chip Duplicate value appears on the field card.
    • Toggle state persists after reload.
    • Special fields do not show this toggle.

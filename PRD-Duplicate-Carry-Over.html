    Duplicate · carry over values

    PRD 08 Status: Shipped Surfaces: Desktop form builder · Desktop journal · Mobile inspection All docs

    Authors mark fields with Option to duplicate value. On duplicate, inspectors can keep those answers — notes never copy. Mobile allows per-field uncheck; desktop keeps all keepable answers.

    1

    Design intent

    • Repeat without retyping stable answers (zone, asset).
    • Author-controlled risk — only opted-in fields are eligible.
    • Notes stay fresh — findings thread never clones.
    • Honest empty state — no dialog if nothing keepable.

    Feature logic

    • Flag optionToDuplicateValue (default off).
    • Keepable = flag + non-empty + uploaded https media.
    • Structure always copies; notes never copy.
    4

    User journey

    1. Author enables Option to duplicate value → sky Duplicate value chip.
    2. Inspector fills fields, taps Duplicate item / “+”.
    3. Chooses Keep vs Empty; mobile may uncheck fields.
    4. New item appears with kept answers; notes blank.

    Batch assign WIS

    PRD 07 Status: Shipped Surfaces: Desktop project issues · Mobile issues All docs

    Multi-select published WIS issues and assign project members in one mode: ADD request. Separate from walk-level Host assign.

    1

    Design intent

    • Clear the backlog fast without opening each WIS.
    • ADD by default keeps existing assignees.
    • One notification per person for the batch.
    • Gated by PROJECT_ADD_EDIT_ASSIGNEE_TO_WIS.
    2

    3

    Feature logic

    PUT /projects/wises/batch/assignee { "wisIdList": [], "assigneeIds": [], "mode": "ADD" }

    Desktop Select All can span pages; mobile Select all is on-screen only.

    4

    User journey

    1. Open project Issues with assign permission.
    2. Batch Assign / Assign FAB → select cards.
    3. Pick members → Confirm Assign / Assign.
    4. List refreshes; assignees updated.

    TC-BA-002

    Batch assign ADD keeps existing assignees

    Pre: Assign permission; ≥2 WIS; Item A already assigned to Alex.

    1. Enter Batch Assign; select Item A and Item B.
    2. Check Priya → Confirm Assign.
    • Item A still has Alex and Priya; Item B has Priya.
    • Success toast; multi-select mode exits.
    TC-BA-003

    One notification per assignee for the batch

    Pre: Assign 5 WIS to one member in a single confirm.

    1. Select 5 items; assign User X once; confirm.
    2. Check User X’s notifications.
    • User X gets one batch notification (not 5 separate).
    • All 5 WIS show User X as assignee.

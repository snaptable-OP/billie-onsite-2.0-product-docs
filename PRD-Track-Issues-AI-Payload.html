    Track Issues · AI payload

    PRD 09 Status: Shipped Surfaces: Mobile Track issues · Desktop Publish to Project · ms-walk AI All docs

    Track Issues builds DRAFT WIS from findings. Title, summary, tags, locations, assignees, and custom fields come from notes; form answers are frozen onto each WIS — not sent to the LLM.

    1

    Design intent

    • Notes tell the story for AI title/details/tags.
    • Forms travel with the issue via frozen requirementJson.
    • Human review before share — DRAFT → edit → publish.
    • Graceful empties — “No special findings” when no note text.

    3

    Feature logic

    CaseConditionAIWIS
    1Text/Voice/MarkdownYesFull AI + freeze forms
    2Attachments onlyNo“No special findings”
    3Forms onlyNoFreeze forms

    LLM gets note text/transcriptions; images as stub text; forms excluded. Custom fields need non-blank descriptions.

    4

    User journey

    1. Capture notes (+ forms).
    2. Publish → Track issues / Publish to Project Workspace → Next.
    3. Flush notes; Billie generates Subject/Details/Tags.
    4. Review, select, publish selected WIS.
    5

    Test cases

    IDStepsExpected results
    TC-AI-001

    Notes produce AI Subject / Details / Tags + frozen forms

    Pre: Host; item has text/voice notes and filled form fields; project has subset tags.

    1. Capture notes describing an issue; fill form fields.
    2. Publish → Track issues (mobile) or Publish to Project Workspace (desktop) → Next.
    3. Wait for generation (“Billie is on it…” / preview load).
    4. Inspect Subject/title, Details, Tags, and requirement/form on the draft.
    • DRAFT WIS title/details/tags reflect note content (LLM Case 1).
    • Form answers appear frozen on the WIS requirementJson / form section.
    • Form field values were not required for title generation beyond notes.
    TC-AI-002

    Attachment-only item → No special findings

    Pre: Item has image attachment(s) in notes but no text/voice/markdown body.

    1. Run Track Issues / Publish to Project Workspace generation.
    2. Open the draft for that item.
    • Title is No special findings (or equivalent Case 2 path).
    • Image URLs appear in WIS content where applicable.
    • No invented long summary from empty text.
    TC-AI-003

    Form-only item (no messages) still freezes forms

    Pre: Item has requirement + form answers; no note messages.

    1. Run Track Issues generation; open draft.
    • Title is No special findings (Case 3).
    • requirementJson includes latest formAnswers.
    • Custom fields / tags from AI are empty for this item.
    TC-AI-004

    Pending offline notes are flushed before AI

    Pre: Mobile offline: add notes that are still pending sync; then regain network.

    1. Immediately run Track issues before notes show as synced.
    2. Confirm drafts reference the new note content.
    • Client flushes pending notes before POST …/ai-summary/full.
    • Generated Subject/Details include the newly flushed note text.
    • If flush fails, generation should not silently ignore pending local-only notes.
    TC-AI-005

    Custom field extraction uses CF description + note text

    Pre: Project dropdown CF “Severity” has a non-blank description and options High/Medium; notes mention “high severity”.

    1. Run Track Issues; open draft custom fields.
    • Severity is set to High when extractor matches an option name.
    • A CF with blank description is not sent to the custom-field AI call.
    TC-AI-006

    Already published items stay locked

    Pre: Item previously published to workspace.

    1. Open Publish / Track Issues preview again.
    • Item shows Published (desktop) / is not republished as a new generation target.
    • Existing WIS is not duplicated by a full regenerate for that issue.
    TC-AI-007

    Publish selected does not complete the inspection

    Pre: Track Issues drafts ready; select a subset.

    1. Desktop: Publish N Items. Mobile: Track N issues / continue with selected.
    2. Return to inspection list/status.
    • Selected WIS appear in project workspace.
    • Inspection is not marked Completed solely by Track Issues (unlike Export report path).
